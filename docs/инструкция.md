# Инструкция на турнир

Приложение считает отбор PAL Trout и плей-офф топ-8. Телефон спортсмена хранит поимки у себя. Официальная таблица собирается на ноутбуке организатора, когда спортсмены показывают QR-код.

На первый живой турнир ведите результат по QR. Кнопка «Обновить данные» подхватывает уловы по Wi‑Fi только пока ноутбук и сервер не перезапускались. Если ноутбук погас и включился снова, сетевые отчёты пропадают, а журнал в браузере организатора остаётся.

## Два адреса

Оба открываются с ноутбука, на котором запущено приложение.

| Кто | Адрес |
| --- | --- |
| Спортсмен | `http://АДРЕС-НОУТБУКА:5174/` |
| Организатор | `http://АДРЕС-НОУТБУКА:5174/admin-secret-setup` |

На самом ноутбуке организатору удобнее `http://localhost:5174/admin-secret-setup`.

Адрес ноутбука в общей сети Wi‑Fi смотрится так:

```bash
ipconfig getifaddr en0
```

Если команда ничего не вывела, ноутбук сидит в другой сети. Телефоны и ноутбук должны быть в одном Wi‑Fi, иначе страница не откроется.

## Перед выездом

1. На ноутбуке нужен Node.js 20. В папке проекта:

   ```bash
   nvm use 20
   npm install
   ```

2. Два окна терминала и оба остаются открытыми весь день:

   ```bash
   npm run back:dev
   ```

   ```bash
   npm run front:dev
   ```

   Первое пишет `Registration API listening on http://127.0.0.1:3001`. Второе открывает страницу на порту 5174.

3. С ноутбука откройте адрес организатора. С телефона откройте адрес спортсмена и убедитесь, что страница грузится.

4. Камера телефона по обычному `http://192.168…` часто молчит. Два рабочих пути:
   - под QR есть поле «Строка QR». Организатор копирует строку под своим кодом, спортсмен вставляет её и нажимает «Принять строку»;
   - в Chrome на телефоне откройте `chrome://flags`, найдите пункт про небезопасные источники (Insecure origins treated as secure), впишите адрес страницы, включите и перезапустите браузер. После этого камера на этом адресе открывается.

5. Зарядите ноутбук и телефоны. Возьмите пауэрбанк. Яркость экрана с QR держите высокой: на солнце код читается плохо.

6. Прогоните дома связку из 2–3 телефонов: открыть турнир, отсканировать старт, ввести один период, сдать QR, увидеть строку в таблице. Кнопку «Сбросить всё» нажимайте только на этой репетиции.

## Вечером: заявки и стартовый лист

Пока есть интернет, спортсмен может оставить ФИО на странице игрока, блок «Предварительная регистрация». Заявка живёт в памяти сервера до его перезапуска. Утром на берегу интернет для ловли уже не нужен.

Организатор на вкладке «Настройка турнира»:

1. Впишите название и дату.
2. Соберите лист одним из способов:
   - «Импортировать список из онлайна» — ФИО встают по порядку заявок, номера 1, 2, 3 без пропусков;
   - «Быстрый старт по номерам» — пустой лист, число приехавших от 2, получатся «Спортсмен №1» и дальше;
   - по одному имени в поле «Участник».
3. Лишних до открытия турнира удалите. Номера сомкнутся. Кнопка «Не пришел» сейчас не работает: неявившегося убирают до кнопки «Открыть турнир». После открытия номер из сетки уже не удаляется, можно только «Заменить» имя.
4. Посмотрите «Секторов на водоёме потребуется». Это половина состава, округление вверх: 9 человек — 5 секторов. В нечётном периоде один спортсмен сидит без пары.
5. Пролистайте «Жеребьёвка» по периодам 1–8. Сверьте сектор и борт с тем, как размечены дорожки.
6. Скачайте «Карточки участников (PDF)» и «Сетку турнира (Excel)». Бумага остаётся, если сядет ноутбук.
7. «Открыть турнир». Появится стартовый QR и строка под ним.

Пока турнир не открыт, быстрый старт по номерам ждёт пустой лист. Если имена уже вписаны, лишних удаляют или лист очищают и собирают заново.

## Утро на берегу

### Организатор

1. Ноутбук включён, оба терминала работают, страница организатора открыта. Вкладку не закрывать и не обновлять без нужды.
2. Покажите стартовый QR. Каждый спортсмен сканирует его один раз. Под кодом есть строка: её можно продиктовать или переслать, если камера не берёт экран.
3. Когда все телефоны написали «Успешно подключен к турниру», можно давать старт.
4. На вкладке «Таблица лидеров» кнопка «Запустить период 1» отмечает старт на ноутбуке организатора. Телефоны сами период не переключают. Вслух назовите номер периода, спортсмены нажимают эту цифру у себя.

### Спортсмен

1. Откройте адрес игрока и не закрывайте вкладку до конца своих периодов. Обновление страницы при пропавшем Wi‑Fi к ноутбуку оставит пустой экран: программа уже в памяти телефона, а с диска ноутбука она без сети не скачается.
2. Если турнира на телефоне ещё нет: «Сканировать жеребьевку организатора». Камера или вставка строки.
3. Стартовый QR на уже работающем телефоне второй раз не сканируют. Повторная запись стирает поимки этого телефона.
4. Выберите свой номер.
5. Введите ФИО и нажмите «Сохранить ФИО». Пока имя не сохранено, кнопки «ПЛЮС» и «Подтвердить» закрыты. Служебное «Спортсмен №3» программа за имя не принимает.
6. На экране крупно: сектор, борт «СЛЕВА» или «СПРАВА», соперник. Борт в сетке меняется от периода к периоду. Идите по надписи на телефоне.
7. Жёлтая плашка «Вы ловите в секторе один» значит: пары нет, ваш улов сравнивается с соседом из соседнего сектора. Соседа на этом экране не вводят, только своих рыб.

## Во время периода

1. Перед ловлей нажмите цифру текущего периода. Крупная цифра в блоке «Период» должна совпасть с объявленной.
2. «ПЛЮС» и «МИНУС» — свои рыбы и рыбы соперника. Оба в паре вводят оба числа. Они должны сойтись: свои у одного — это чужие у другого.
3. В конце периода «Подтвердить результат периода». Надпись сменится на «Период сохранён».
4. Периоды 1–7 остаются в телефоне. Организатору их по одному не сдают.
5. Если период подтвердили с ошибкой, скажите организатору. Он правит ячейку в таблице после того, как примет ваш QR. На телефоне уже закрытый период сам не переписывается.

Очки периода считает программа, на телефоне их вводить не нужно:

| Ситуация | Очки |
| --- | --- |
| Больше рыб, чем у соперника | 4 |
| Поровну, и оба поймали хотя бы одну | 2 каждому |
| Меньше, но своя рыба есть | 1 |
| Ноль рыб, в том числе 0:0 и сухой проигрыш | 0 |

Место в отборе: сначала сумма очков, при равенстве — сумма рыб, дальше меньший номер.

## После 8-го периода

Спортсмен:

1. Подтвердите каждый период. На цифрах 1–8 должно быть «Период сохранён». Ноль рыб тоже нужно подтвердить: пустой период в журнале не считается.
2. «Сгенерировать QR-код результатов» остаётся неактивной, пока в телефоне не закрыты все восемь. Под кнопкой видно, сколько уже сохранено.
3. Когда кнопка стала белой, нажмите её и покажите код организатору. В окне виден список периодов: сверьте рыбы до того, как отойти.
4. Если камера организатора не читает экран, нажмите «Скопировать» и передайте строку.

Организатор, вкладка «Сканировать QR»:

1. Камера или вставка строки. Успешный приём пищит и пишет номер, ФИО и число рыб.
2. Один код — весь отбор этого спортсмена. Кубковый матч потом придёт отдельным кодом.
3. Откройте «Таблица лидеров». Ячейка периода читается как «свои : соперник (очки)».
4. Оранжевая ячейка — двое назвали разный счёт. Клик по ячейке открывает правку. Имя открывает карточку спортсмена.
5. Кнопка «Сформировать Плей-офф» появляется, когда закрыт 8-й период у всех, кто в этот период сидел в сетке. Для сетки нужны минимум 8 спортсменов. В кубок идут первые 8 мест. Пары: 1–8, 2–7, 3–6, 4–5.

Если в турнире меньше 8 человек, отбор и таблица работают, кнопка плей-офф ответит «Для плей-офф нужны 8 спортсменов в таблице». Итог отбора тогда фиксируйте таблицей и файлом Excel.

## Плей-офф

Ничья основного времени снимается по очереди:

1. Дополнительная 5-минутка.
2. «Золотая рыба»: больше рыб, а при равном ненулевом счёте — кто поймал первым. Это нужно отметить кнопкой.
3. Если в золотой рыбе 0:0, проходит более высокое место отбора.

Спортсмен выбирает свою кубковую пару и свой номер, вводит поимки, подтверждает дуэль и сразу показывает «QR-код матча». Организатор принимает его на той же вкладке сканера. Тот же ввод есть у организатора: в сетке нажмите пару и заполните окно «Поимки этапа».

Когда сыграны финал и матч за 3-е место, появляются подиум, итоговая таблица и кнопка «Завершить и архивировать турнир». Архив пишется в PostgreSQL на ноутбуке. Без запущенной базы кнопка не сохранит страницу. На первый турнир снимите подиум и ещё раз скачайте Excel до того, как закрывать ноутбук.

Страница архива открывается по ссылке, которую программа покажет после успешной записи. Ссылка жива, пока жив сервер и база.

## Чего не нажимать в день турнира

- «Сбросить всё (Hard Reset)» на ноутбуке стирает журнал организатора: лист, сетку, уловы и плей-офф.
- «Очистить лист» до открытия убирает стартовый состав.
- Повторное сканирование стартового QR на телефоне стирает уже введённые там поимки.
- Закрытие вкладки и обновление страницы при пропавшей связи с ноутбуком гасит экран. Данные периода, которые уже подтвердили, лежат в браузере этого телефона, но без открытой вкладки до них не добраться, пока страница снова не загрузится с ноутбука.

Если телефон спортсмена завис до сдачи QR, не сбрасывайте турнир на ноутбуке. Откройте на этом телефоне ту же вкладку: подтверждённые периоды должны быть на месте. QR можно собрать снова.

## Короткая памятка спортсмену

1. Открыть адрес, который дал организатор. Вкладку не закрывать.
2. Один раз сканировать стартовый QR.
3. Выбрать свой номер, вписать ФИО, сохранить.
4. На каждый период нажать его цифру, сверить сектор и борт.
5. Плюс и минус по своим и по сопернику. В конце периода — «Подтвердить».
6. После отбора кнопка QR включается, только когда сохранены все восемь периодов. Тогда показать один код организатору.
7. В плей-офф после каждой дуэли показать отдельный QR сразу.
