# Fishing Tournament Portal

Офлайн-журнал турнира по форели: телефон спортсмена пишет поимки, ноутбук организатора собирает таблицу по QR и считает плей-офф топ-8.

- [Инструкция организатору и спортсменам](docs/инструкция.md) — как провести турнирный день.
- [Работоспособность и что доработать](docs/работоспособность.md) — что уже можно выносить на водоём и какие границы у текущего MVP.

Запуск на ноутбуке, два терминала:

```bash
nvm use 20
npm install
npm run back:dev
npm run front:dev
```

Спортсмен открывает `http://АДРЕС-НОУТБУКА:5174/`. Организатор — `http://localhost:5174/admin-secret-setup`.
